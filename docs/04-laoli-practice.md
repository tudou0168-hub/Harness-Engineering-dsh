# Laoli Practice Cases

## 研究定位

将真实项目作为 DSH 工程验证案例。

## 案例一：PPT Production Agent

目标：

基于 DSH 构建专业 PPT 生产智能体。

核心研究：

- Agent 分工模式
- Context 管理
- Skill 组织
- 长流程任务控制
- UI 工作流设计

## 案例二：企业智能体平台

目标：

构建面向企业生产的个性化 AI Agent。

研究重点：

- 专业 Agent 模板
- 企业知识接入
- 工作流编排
- 权限控制
- 可追溯执行

## 问题沉淀

所有真实研发问题记录：

问题现象 → 所属层级 → 定位方法 → 解决方案 → 工程经验

形成可复用专家知识库。
