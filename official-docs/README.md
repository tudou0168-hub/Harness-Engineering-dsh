# DeepSeek Harness Official Documentation Extraction

本目录用于沉淀 DeepSeek Harness 官方开发文档与参考文档，并转化为我们的工程研究资料。

来源：
- Official Reference: https://deepseek-harness.github.io/deepseek-harness/reference/
- Official Develop Basic: https://deepseek-harness.github.io/deepseek-harness/develop/basic/

研究原则：

1. 保留官方术语。
2. 不替代官方文档，而是在其基础上增加工程解释。
3. 每个能力增加：用途、扩展点、适用场景、问题定位方法。
4. 优先服务于个人工作台、企业 Agent、PPT Agent、政务 Agent 开发。
