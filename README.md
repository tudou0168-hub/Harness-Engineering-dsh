# Harness-Engineering-dsh

这是一本关于 Harness Engineering 与 DeepSeek Harness（DSH）工程实践的研究项目。

## 项目定位

本项目不复刻官方产品文档，也不做纯理论介绍。

研究目标是基于：

- DeepSeek Harness 公开发布包
- 源码结构分析
- 社区 Plugin 实现案例
- 实际 AI Agent 项目开发经验

提炼一套可以指导真实生产研发的 AI Agent 工程方法。

## 核心目标

重点回答以下问题：

1. 基于 DSH 可以构建什么类型的 AI 应用平台？
2. 如何开发自己的 UI、Plugin、Agent、Skill、Tool？
3. 如何组织企业级智能体架构？
4. 遇到问题时如何快速定位问题层级？
5. 如何从 Demo 走向稳定生产系统？

## 研究重点

- DSH Extension Architecture
- Plugin 开发模式
- Agent 定制方法
- UI 工作台建设
- Context 管理策略
- Permission 与 Runtime 控制
- 企业 Agent 工程实践
- 问题诊断案例库
