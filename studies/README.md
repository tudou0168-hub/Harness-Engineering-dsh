# Studies

专项研究工作区。这里允许保留尚未提升为稳定结论的分析、实验和比较。

建议命名：

```text
YYYY-MM-DD-topic.md
```

每个 study 建议包含：

- Question
- Baseline
- Sources
- Reproduction
- Observed facts
- Competing explanations
- Finding
- Production implication
- Whether promoted to docs

研究完成后，把仍成立的规则提炼到 `docs/`；不要让 `docs/` 变成研究过程堆积区。
