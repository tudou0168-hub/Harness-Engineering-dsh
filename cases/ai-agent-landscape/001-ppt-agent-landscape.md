# 案例 001 · PPT Agent 生态研究

## 案例来源

公开社区中已经出现多种 PPT Agent 实现，包括单体生成、流水线 Agent、多 Agent 协作和带视觉审查的方案。

例如：

- ppt-agent：从文本或 URL 输入生成演示文稿，包含分析、扩展、生成、质量检查流程，并提供主题、布局、多轮修复等能力。
- 多 Agent PPT 项目：采用 research、content、slide、review 等角色拆分。
- PresentAgent：进一步将文档转为带讲解的视频演示。

## 架构观察

### 普通方案

```text
输入材料
 ↓
LLM生成内容
 ↓
模板填充
 ↓
导出
```

问题：
- 缺少专业判断；
- 缺少中间状态；
- 无法稳定复用。

### 更成熟方案

```text
材料理解
 ↓
结构规划
 ↓
内容生成
 ↓
视觉设计
 ↓
质量检查
 ↓
人工确认
 ↓
输出
```

## 对 Laoli PPT Agent 的启发

保留：

- 专业 Prompt
- 阶段化状态
- 用户确认点
- 可追溯产物
- 视觉检查

不要简单复制：

- 大量 Page Agent 并行；
- 复杂状态机；
- 为了检查而增加大量 Gate。

## DSH 映射

适合放置：

- Preset：PPT 专业模式
- Skill：文案导演、视觉导演
- Tool：文件处理、渲染、检查
- Plugin：项目工作台、预览界面
