# AI Agent 实战案例库

## 研究目标

不是收集 AI 产品，而是分析：

- 这些 Agent 解决什么真实工作问题；
- 采用什么 Agent 架构；
- 哪些能力应该落到 DSH Plugin / Preset / Skill / Tool / UI；
- 哪些经验可以迁移到 Laoli AI Workspace。

## 案例分类

- 自媒体内容生产 Agent
- 公文/方案写作 Agent
- PPT 生产 Agent
- 网络研究与数据采集 Agent
- 个人工作台 Agent
- 企业知识工作台 Agent

## 分析模板

每个案例记录：

1. 用户场景
2. 核心工作流
3. Agent 角色划分
4. Context 与状态管理
5. UI 交互设计
6. 可借鉴点
7. 不建议复制点
8. 对 DSH 自研方向的启发
