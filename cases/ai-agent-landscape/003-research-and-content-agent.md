# 案例 003 · 自媒体 / 研究 / 内容生产 Agent

## 场景

面向：

- 自媒体运营
- 行业研究
- 内容策划
- 长文章生产
- 数据采集

## 推荐工作流

```text
热点发现
 ↓
资料采集
 ↓
事实验证
 ↓
观点提炼
 ↓
内容生产
 ↓
多平台改写
 ↓
发布分析
```

## Agent 分工

不建议：

一个万能 Agent 包办全部。

建议：

- Research Agent：找资料、整理证据
- Editor Agent：形成观点
- Content Agent：适配平台
- Analytics Agent：分析反馈

## DSH 映射

Research：Tool + Skill

写作：Preset + Skill

数据采集：Tool

内容工作台：Plugin UI

## Laoli 方向

可形成：

AI 内容生产工作台

覆盖：

- 小红书
- 视频号
- 公众号
- PPT
- 方案材料

核心不是自动生成，而是建立个人长期生产系统。
